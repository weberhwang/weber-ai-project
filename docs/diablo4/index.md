# Diablo 4

暗黑破壞神 4 的研究筆記。

## 待整理心得

### 傷害公式
傷害公式=武器傷害 * 主屬性 * A傷區 * B傷區 * 獨立區  
A傷區=前面有[+]的  
B傷區=前面有[x]的  
獨立區=後面有[x]的  
挑選時，獨立 > B傷區 > A傷害

### 職業主屬性判斷
在人物面板的屬性(智力、力量、意志、敏捷)上看，  
若有某一個有技能傷害加成，該屬性則為主屬性

### 寶石都要拆成「某某」寶石碎片，再往上合成

### 寶箱
- 蘇波精鑄寶箱(傳奇友好度寶箱):  
  包含精鑄材料(歐杜希特)及傳奇護身符
- 混沌收藏(低語寶箱): 裝備、雕文

### 裝備篩選
- 稀有靴子: 3 屬性以下的直接拆
- 稀有手套: 3 屬性以下的直接拆
- 稀有護身符: 3 屬性以下的直接拆
